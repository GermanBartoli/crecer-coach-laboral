# Guía de crecer-coach-laboral

Editá las publicaciones en `content.json`. Conservá la correspondencia entre cada entrada, su red y sus archivos en `assets`. `tests/content.test.js` comprueba los grupos, imágenes, videos y vías de contacto.

Corré `pnpm run check`, `pnpm test` y `pnpm run build`. Con `pnpm run dev` podés revisar la publicación editada y reproducir su clip.

Consultá los pasos de publicación en [el flujo de GitHub Actions](.github/workflows/cloudflare.yml). Para verificar los dos sitios publicados, seguí [la guía de publicación](docs/PUBLICACION.md).
